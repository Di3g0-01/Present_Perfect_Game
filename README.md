# Study Abroad Adventure - English Practice Game

Welcome to the **Study Abroad Adventure**, an interactive web game designed to help students practice English vocabulary and grammar related to studying abroad! 

## Features

*   **Interactive Levels:** Progress through different levels, each focusing on specific language skills.
*   **Gamified Learning:** Defeat bosses, solve puzzles, and test your knowledge in a fun environment.
*   **Vocabulary Building:** Practice essential words like *Attend*, *Scholarship*, *Abroad*, *Accommodation*, and more.
*   **Responsive Design:** Playable on various screen sizes for learning on the go.

## Technologies Used

*   **React:** For building the interactive user interface.
*   **Vite:** For fast development and building.
*   **Tailwind CSS:** For styling the components.

## Getting Started

To run this project locally:

1.  Clone the repository.
2.  Install dependencies: `npm install`
3.  Start the development server: `npm run dev`

## Deployment

This project is configured to be easily deployed on **Vercel**. 

1.  Push your code to a GitHub/GitLab/Bitbucket repository.
2.  Import the project in Vercel.
3.  Vercel will automatically detect the Vite framework and configure the build settings.
4.  Deploy!
